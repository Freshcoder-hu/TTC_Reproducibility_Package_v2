# Evidence boundaries and study limitations / 统计边界

*主实验*：评估种子 2000–2029，标定种子 1000–1019。377/2400 在时域内未达终点，
全部保留在分母中。主文九场景等权：V2S4M 与 V2S2 几何重复，十场景聚合仅为敏感性检查。

*鲁棒性*：固定 3000–3029 种子，观测丢失是周期性共享失联代理而非真实视觉遮挡；
位置噪声为每轴高斯标准差，速度及目标类型等仍保留简化假设。
主要接触度量 C 是每运行中发生**动物–障碍物**接触的动物比例。
机器人–动物、机器人–障碍物、机器人–机器人接触应分开报告。
新增安全层并未实现零实体重叠，机器–障碍物接触仍可能发生。

*在线*：事件可观测、控制器响应和执行层放行是不同概念；
参考外推碰撞时间不等于实际物理接触时间。
若没有发生实体接触，不应强行填造接触提前量；
132 次回放存在场景、目标与机器人相关性，不宜当成大量独立二项检验。
串行软件计时未覆盖真实传感器、网络和机器人硬件。
